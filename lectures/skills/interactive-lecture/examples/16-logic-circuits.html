PRACTICE 1 / 学習ノート 実習1

空欄に入る語と数（語群から選ぶ）

空欄①〜④をタップすると答えが表示されます。③ の 4 通り と ④ の真理値表 が、次の実習2 で使う道具です。

コンピュータでは、「0」と「1」の2種類の信号で演算や制御を行う。この演算や制御を行う回路を（①）という。（①）は、回路ごとに入力信号に対する出力信号が決められており、たくさんの回路が存在する。例えば、（②）回路は、二つの入力と一つの出力をもつ回路で、二つの入力信号が1のときだけ、出力信号が1になる回路である。二つの入力信号の組み合わせは、全部で（③）通りあり、入力信号が「1」と「1」のときだけ出力信号が「1」で、それ以外は「0」となる。この入力と出力の関係を表す表を（④）と呼ぶ。
《語群》 ア．真理値表　イ．論理回路　ウ．NOT　エ．AND　オ．OR　カ．0　キ．1　ク．2　ケ．4

解答は ① イ、② エ、③ ケ、④ ア です。二つの入力がそれぞれ 0 か 1 なので、組み合わせは 2 × 2 ＝ 4 通り。真理値表はその 4 行です。

APPENDIX A / ベストフィット 思考のステップ4

3 路スイッチの配線で、真理値表を作る

1 つの電灯を 2 か所のスイッチで点けたり消したりするために、3 路スイッチ が使われます。上側に切り替わったときを 0、下側を 1、電灯が点いたときを 1 とします。スイッチをタップして切り替え、電流の通り道を目で追ってください。

同じ側なら点く

上の線か下の線が、電源から電灯までつながる

A と B が同じ側（0・0 か 1・1）のとき、上の線か下の線のどちらかが電源から電灯までつながって点灯します。違う側なら途中で切れて消灯です。真理値表は 1・0・0・1 になります。思考のステップ4 の問1 は、この表と同じ出力になる論理回路を選ぶ問題です。

学習ノートとの違い

1 の決め方が違うだけで、仕組みは同じ

学習ノート実習2 は押す＝1 で、両方押すと消灯（0・1・1・0）でした。ここでは下側＝1 で、同じ側なら点灯（1・0・0・1）です。1 の決め方が違うだけで、どちらも「2 つのスイッチが同じか違うか」で決まる回路です。

APPENDIX B / ベストフィット 思考のステップ4 問2

3 か所のスイッチは、4 路スイッチをはさむ

スイッチを 1 つ増やして 3 か所から操作するには、真ん中に 4 路スイッチ C を入れます。C は 2 本の線を まっすぐつなぐ（0）か、交差させる（1） かを切り替えます。入力が 3 つなので、真理値表は 8 行です。

C を切り替えると

点灯と消灯が、必ず入れ替わる

表を上から 2 行ずつ（A・B はそのままで、C だけが違う組）見ると、1 と 0、0 と 1、0 と 1、1 と 0 です。C を切り替えるたびに、点灯と消灯が入れ替わります。ほかの 2 つの入力をそのままにして、A だけ、または B だけを切り替えても、同じように入れ替わります。だから 3 か所のどこからでも点けたり消したりできます。

C ＝ 0 の行だけ見ると

参考A の 3 路スイッチと同じ並び

C ＝ 0 の 4 行（1・3・5・7 行目）は、線がまっすぐなので参考A と同じ 1・0・0・1 です。C ＝ 1 の 4 行（2・4・6・8 行目）は、それを反転した 0・1・1・0 です。8 行を通すと 1・0・0・1・0・1・1・0 になります。

APPENDIX C / ベストフィット 例題48

「一方のみ 1」の回路を、AND・OR・NOT で組む

階段スイッチや半加算回路の S に出てきた「どちらか一方のときだけ 1」は、OR回路の出力と、AND回路の出力を NOT回路で反転したものを、AND回路にまとめると作れます。学習ノート実習3 の図の S の部分がそれです。ボタンで入力を選ぶと、各回路の出力が図に出ます。

なぜこの形か

「少なくとも一方が 1」かつ「両方 1 ではない」

OR回路は「少なくとも一方が 1」、AND回路を NOT回路で反転したものは「両方 1 ではない」を表します。この 2 つが同時に成り立つのは、一方だけが 1 のときです。だから最後を AND回路でまとめます。

図記号と名前

ベストフィットでは排他的論理和回路（XOR回路）

例題48 の解説は、この回路を 排他的論理和回路（XOR回路） と呼び、「二つの入力のうち、一方のみ 1 のときだけ出力が 1」と説明しています。図記号は OR の左に線を 1 本足した形です。学習ノートでは名前を付けず、AND・OR・NOT の組み合わせとして扱っています。

APPENDIX D / 学習ノート POINT ⑦

下位からの桁上げも足す、全加算回路

2 桁以上の足し算では、下の桁からの桁上げも足さなければなりません。A・B・下位からの桁上げ の 3 つを入力にして、S と C を出す回路が全加算回路です。3 入力なので真理値表は 8 行、1 ＋ 1 ＋ 1 ＝ 11 で S ＝ 1、C ＝ 1 になります。

半加算回路を 2 つ重ね、2 つの桁上げを OR回路でまとめる
半加算回路を 2 つ使う

A ＋ B の S に、下位からの桁上げをもう一度足す

A ＋ B を半加算回路①で足し、その S に下位からの桁上げを半加算回路②で足します。桁上げは ① と ② のどちらか一方でしか出ないので、2 つの C を OR回路でまとめると全体の C になります。A ＋ B で桁上げが出るのは A と B がともに 1 のときで、そのとき半加算回路①の S は 0 です。0 に下位からの桁上げを足しても、半加算回路②からは桁上げが出ません。

何桁でもつなげる

C を次の桁の「下位からの桁上げ」につなぐ

全加算回路の C を次の桁の入力につなぐと、4 ビットの足し算回路になります。前回の 0110 ＋ 1101 ＝ 1 0011 のような計算は、この回路を 4 つ並べたものが行っています。
