# 情報Ⅰ 2学期

50分の授業1回ぶんを、5つの教材キットにまたがってそろえる場所。

## 50分の型

| | 何を使うか |
|---|---|
| 25分 解説 | 手持ちスライド + 解説ツール（動かして見せる） |
| 15分 プリント演習 | 印刷プリント（紙で解いて、その場で解説する） |
| 10分 スピードテスト | スピードクイズ（速さ×正答率で復習する） |

学習ノート（`lectures/`）と問題集（`practices/`）は**個人学習用**。授業内では使わない。
1学期のアンケートを受けて役割を分けた。作る質は落とさない。

## 作り方

```
/joho-2gakki    テーマを指示すると、1回ぶんを一式そろえる
```

規則は `CLAUDE.md`。難所の選び方は `_ops/nansho-guide.md`。
各教材の作り方は、それぞれのキットの指示書が持つ（ここでは決めない）。

## コマンド

```bash
python3 _ops/build_kai.py 1        # 第1回の回フォルダを正本から組む
python3 _ops/build_kai.py --all    # 全回を組み直す
python3 _ops/build_kai.py --index  # 回の一覧だけ作り直す
python3 _ops/check_public.py       # 公開安全ゲート（push 前に必ず）
```

## 台帳

`_ops/manifest.toml` が唯一の正本。回の一覧・POINT と節の対応・配信先はここだけで持つ。
回フォルダと `index.html` は生成物なので手で書かない。

## 注意

このリポジトリは **public**。`_teacher/` と `02_プリント/`（解答を含む）は `.gitignore` で外してある。
手元には残るが公開されない。詳細は `CLAUDE.md` §4。
