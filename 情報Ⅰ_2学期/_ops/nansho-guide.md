# 難所の選び方

50分に3つの教材を入れるのだから、扱う難所は1つに絞る。
ここを間違えると、3点そろっていても授業は散る。**教材を作る前に読む。**

---

## 1. 難所とは何か

**初見の生徒が落ちる場所**であって、内容として重要な場所ではない。この2つはよくずれる。

| | 例 |
|---|---|
| 重要だが難所ではない | 「標本化・量子化・符号化の3語」— 順に並べれば覚えられる |
| 難所 | 「標本化周波数が信号の2倍を下回ると、元と違う波に化ける」— 化けた波が**別のもっともらしい波として存在してしまう**ところで詰まる |

判定は1つ。**その場所を飛ばして先へ進めるか。** 飛ばせるなら難所ではない。

---

## 2. 難所の4類型

情報Ⅰで実際に詰まる場所は、だいたいこの4つに入る。

### 型A — 境界がある

条件を満たすか満たさないかで結論が反転する。境界のすぐ両側で何が違うかが見えない。

- 標本化周波数と、元の信号の2倍（下回った瞬間に別の波になる）
- 二分探索が使えるか（並んでいるか）
- 8ビットで表せる範囲と、その1つ外側
- サブネットマスクで同じネットワークか別か

→ **解説ツールの状態判定バナーがそのまま使える。** 型Aは explainer と相性が最もよい。

### 型B — 順序を入れ替えると壊れる

手順は覚えているのに、順序が入れ替わると答えが合わなくなる。

- 補数を取ってから足すのか、足してから捨てるのか
- 10進→n進は「商が0になるまで割り、余りを下から並べる」（下から、が抜ける）
- 論理演算の優先順位（NOT → AND → OR）
- 整列アルゴリズムで、比較と交換のどちらを数えているか

→ **プリントで手を動かさないと直らない。** 型Bは印刷プリントが主役。

### 型C — 似ているが違う

2つの概念が近すぎて、どちらの話をしているか見失う。

- 可逆圧縮と非可逆圧縮（「中身を保ったまま」は非可逆と矛盾する）
- モールス信号の「間」による区切りと、ハフマン符号の接頭符号（**同じではなく、よく似ている**）
- 相関と因果
- 変数の値渡しと参照渡し
- IPアドレスとMACアドレス

→ **スピードテストの誤答選択肢に「もう一方」を置く**と、取り違えがそのまま点数に出る。

### 型D — 数えると合わない

直感で出した数と、実際に数えた数が食い違う。

- ランレングスは2個だと短くならない（`BB` → `B2` は同じ長さ。3個以上で初めて縮む）
- 二分探索の計算量が log になる（100件が7回で終わることが直感に反する）
- 待ち行列で、平均到着率が平均処理率を少し下回るだけでも行列が伸びる
- 標準偏差が外れ値1つでどれだけ動くか

→ **3点すべてで同じ数値を使い、3度数えさせる。**

## 3. 難所の見つけ方（この順で当たる）

1. **原本の解答を読む。** 解答PDF・ベストフィット解答で、解説が長い設問がある。
   出題者が長く書いた場所が難所。
2. **前年の指摘を読む。** `.company/audit/reviews/**` に codex が拾った概念の破綻が残っている。
   自分が書き間違えた場所は、生徒も間違える。
3. **自分で解いてみて、手が止まったところ。** 止まった理由を1文で書けたら、それが難所。
4. **共通テストの過去問で、正答率が落ちる形式。** 図の読み取りと計算が混ざる設問。

---

## 4. 難所を1文で書く

`_ops/kai/NN-<slug>.md` の `nansho` に、**生徒が何をどう間違えるか**を書く。
「難しい」「理解しづらい」では作れない。

- 悪い: 「補数の理解が難しい」
- 良い: 「補数を取る操作と、桁あふれを捨てる操作を別々に覚えてしまい、順序が入れ替わると答えが合わなくなる」

- 悪い: 「標本化定理がわかりにくい」
- 良い: 「標本化周波数が足りないとき、元と違う波が**もっともらしく**再現されることに気づかず、
  『粗くなる』と誤解する」

後者の形なら、そのまま3点に落ちる。

---

## 5. 3点への落とし方

難所を書けたら、次の3行を埋める。埋まらないなら難所の書き方が粗い。

```
① 解説ツール  : 何を操作すると、何が切り替わって見えるか
② プリント    : どの空欄が、その難所を通らないと埋まらないか
③ スピードテスト: どの誤答選択肢が、その取り違えそのものか
```

例（標本化定理・型A）

```
① 標本化周波数のスライダーを下げると、再現波が別の波に化け、バナーが warn に変わる
② 「元の信号が 3.4 kHz のとき、必要な標本化周波数は ____ Hz 以上」を桁固定で書かせる
③ 誤答に「粗い波になる」を置く（正答は「別の低い周波数の波になる」）
```

---

## 6. 却下すべき「難所もどき」

- **用語の暗記**（プロトコル名、装置名の羅列）。詰まるのではなく、覚えていないだけ。
- **計算が長いだけ**。手順は一本道で、途中で判断が要らない。
- **図が複雑なだけ**。読み取れば書いてある。
- **教科書に書いていない発展**。50分で扱う難所ではない（lectures の発展スライドへ回す）。

これらを難所に据えると、解説ツールに操作させる対象がなく、誤答選択肢が無関係なダミーになる。
**整合ゲート（`../CLAUDE.md` §7）で必ず引っかかる**ので、その前に落とす。

---

## 7. 1回に2つ入れたくなったら

分ける。50分に難所を2つ入れると、3点それぞれが2つの話をすることになり、どれも浅くなる。
`_ops/manifest.yaml` の `kai` に2回ぶん起こして、アンカーを共有させればよい
（同じ POINT に複数の回がぶら下がってよい）。
