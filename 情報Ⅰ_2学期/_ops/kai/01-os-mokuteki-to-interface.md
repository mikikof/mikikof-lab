# 第1回 装置の違いを意識せずに使えるのは誰の仕事か

## 難所（1つだけ）

> 「装置の違いを意識せずに使える」状態を作っているのが**どの層か**が決まらない。
> ハードウェアインタフェース（コネクタの形状や電気信号の形式などの仕様を合わせる）と
> OS の抽象化（装置の違いを意識せず利用できるよう操作の内容を抽象化する）は、
> どちらも「違いを吸収している」と読めてしまう。そのため実習5「OS の目的として
> 正しくないもの」で、イ（仕様を合わせる）とエ（操作の内容を抽象化する）のどちらを
> 選ぶかが運になる。

**型**: C 似ているが違う

### なぜここが難所だと言えるか（原本の重み）

POINT 14 の実習で、原本の解説が**理由まで書いているのは実習5イ ただ1件**。

| 設問 | 原本の解説の書き方 |
|---|---|
| 実習4 | 「イは、インストーラ、ウはマルウェア、エはOS」— ラベルのみ |
| 実習6 | 「アはAPIの説明」「イはインタフェースの説明」「ウは機械学習の説明」— ラベルのみ |
| **実習5イ** | **「ハードウェアのインタフェースの標準化の話なので、OSの目的ではない」— 理由つき** |

しかも取り違えの相手（エ）が**同じ4択の中に置かれている**。型C の条件が原本の設問構造そのもので満たされている。

この POINT は放っておくと用語の暗記になる（`../nansho-guide.md` §6 の却下対象）。
層の帰属という軸が、この単元を暗記から救っている。

## 3点への落とし方

| | 何をするか |
|---|---|
| ① 解説ツール | スイッチ2つ。**②OS 側の用意**を切ると判定が warn になる。**①規格**をどう動かしても判定は動かない（上の読み取り欄だけが変わる）。「規格をそろえる仕事は OS の判定に入ってこない」が操作で見える |
| ② プリント | 大問3の誤文訂正。**前半（OS の目的）と後半（規格の仕事）を切り分けないと1文字も書けない** |
| ③ スピードテスト | 誤答に「USB という規格。コネクタの形状と電気信号の形式をそろえている」を置く。取り違えがそのまま点数に出る |

## 共通の例と数値（3点で一致させる正本）

**場面**: USB ケーブルでつないだプリンタ1台を、文書作成ソフトから使う。

| 項目 | 値 | 出典 |
|---|---|---|
| 固有名詞 | **一つも作らない**（メーカ名・製品名・OS 名・型番はすべて原本に無い） | — |
| 数値 | **使わない**（型C。個数・台数を判定に持ち込まない） | — |
| 判定に使う語 | 「装置の違いを意識せず利用できるよう操作の内容を抽象化する」 | 実習5エ |
| 引用としてのみ使う語 | 「周辺機器の違いをほとんど意識することなく作業ができる」 | 実習2 本文 |
| 共有する記号 | 実習5 の ア・イ・ウ・エ | 実習5 |
| OS の目的3語 | 操作支援／基本機能の提供／資源の有効利用 | POINT 14-3 |
| 共有する判定状態 | ①規格はそろっている ②OS はこのプリンタ用のデバイスドライバを持っていない | — |

**独立検算**: この回は数値を使わないため計算の検算は無し。代わりに**正答の照合**を行った
（実習1〜6 は解答PDF p.10、例題39〜42・類題68〜71・練習72〜74 はベストフィット3章解答）。
ベストフィット練習74（USBハブ）は独立に計算し `4＋3×4＝16台` で原本解説と一致したが、
**この回では使わない**（型D の難所であり、一回一難所を割る）。

### 使わないと決めたもの（根拠が弱い／難所を割る）

| | 理由 |
|---|---|
| 類題70（デバイスドライバ ○×） | 「挿すだけで自動インストール」に踏み込むと難所が逆向きに定着する |
| 練習73（層の並べ替え） | 順序は今回の難所と別の軸。lectures / practices（授業外）へ回す |
| 練習74（USBハブ 16台） | 型D。一回一難所を割る |
| 実習6（IoT・API） | 難所に入れない。まとめスライドで穴埋め語として1行だけ触れる |

### 原本に明文が無いので書かないこと

- 「規格がそろっていないと**印刷できない**／壊れる／出力先に出てこない」
  → 画面の文言は「規格がそろっていません」に留める
- 「OS の側に用意がないと**印刷できない**」
  → 原本にあるのは肯定形（実習2）だけ。否定形の帰結を足さない
- 「機種」という語を判定文に使わない（正答が確定している範囲に無い）
