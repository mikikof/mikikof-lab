# 第3回 「どちらか一方のときだけ」は OR ではない

## 難所（1つだけ）

> 「どちらか一方が押されたときだけ点く」を「どちらかが押されたら点く（OR）」と取り違え、
> 両方が 1 の行で真理値表を 1 と埋めてしまう。違いが出るのは A＝1・B＝1 の 1 行だけなので、
> 4 行のうち 3 行が合っていて気づかない。

**型**: C 似ているが違う

### なぜここが難所だと言えるか（原本の重み）

- 学習ノート 16 の実習2（階段スイッチ）は、解答 PDF（p.10）の解説がこの POINT で最も長い。
  「二つのスイッチの状態が異なるとき点灯し、同じとき消灯」と、言葉で言い直すところまで書いてある。
  実習3 は半加算回路で、S（1 桁の和）が「どちらか一方のときだけ 1」、C（桁上げ）が AND。
  実習4・5 は真理値表と回路の対応を選ばせ、真理値表の 1 行の違いで選択肢を落とす。
- ベストフィット 思考のステップ4 は同じ階段（3 路）スイッチを共通テスト型にし、
  「考えて納得！」で真理値表の埋め方（行数 2^n、A は上半分 0・下半分 1、B はその半分ずつ）を手順にしている。
  問2 は 3 入力 8 行。例題48 の解説は「(ウ)は排他的論理和回路（XOR回路）と呼ばれ、二つの入力のうち、一方のみ「1」のときだけ出力が「1」」。
- OR で 3 行まで合ってしまうので、飛ばして先へ進める。`nansho-guide.md` §1 の判定で難所に当たる。

## 3点への落とし方

| | 何をするか |
|---|---|
| ① 解説ツール（A 状態判定バナー型） | スイッチ A・B をタップし、ランプと真理値表の行が埋まる。回路を「階段スイッチ（どちらか一方のときだけ）」「OR」「AND」で切り替え、目標（階段スイッチ）と食い違う行でバナーが warn。両方 1 の行だけが OR と分かれる。3 か所のスイッチ（3 入力 8 行）のプリセットで、行の埋め順（A 上半分 0・下半分 1…）を見せる |
| ② プリント（A 穴埋め記述型・常体） | 例題は階段スイッチの真理値表（実習2 そのもの）。OR の表を横に置き「違う行」を書かせる空欄は、両方 1 の行を見ないと埋まらない。大問で 3 入力 8 行を決まった順に埋め、真理値表から回路を消去法で選ぶ |
| ③ スピードテスト | 旗艦 Q2 の誤答に OR の真理値表（0 1 1 1）と AND（0 0 0 1）を置く。Q3 で「OR と違う行」を直接問う。半加算回路の S と C を問い、POINT 15 の 1＋1＝10 とつなぐ |

## 共通の例と数値（3点で一致させる正本）

入力は A・B（3 入力のときは A・B・C）、出力は L（ランプ）または X。真理値表の行は A・B の順で 00・01・10・11。

| 項目 | 値 | 出典（原本の該当箇所） |
|---|---|---|
| 主例 | 階段スイッチ。押す＝1・戻す＝0、点灯＝1・消灯＝0。両方押すと消灯 | 学習ノート 16 実習2（解答 p.10） |
| 階段スイッチの真理値表 L | 00→0、01→1、10→1、11→**0** | 同上（0・1・1・0） |
| OR の真理値表 | 00→0、01→1、10→1、11→**1** | 学習ノート POINT ④ 論理和回路の定義 |
| AND の真理値表 | 00→0、01→0、10→0、11→1 | 学習ノート POINT ③ 論理積回路の定義 |
| 違いが出る行 | A＝1・B＝1（OR は 1、階段スイッチは 0） | 上の 2 表の差 |
| 半加算回路 | S（和）＝ 0・1・1・0、C（桁上げ）＝ 0・0・0・1。空欄 Ⓐ は AND | 学習ノート 16 実習3（解答 3: ①ア ②キ ③イ ④ウ） |
| 1＋1＝10 | S＝0、C＝1 | 学習ノート 15 実習1（1⑵＋1⑵＝10⑵） |
| 3 入力 8 行の埋め順 | 行数 2³＝8。A は上 4 行 0・下 4 行 1、B は 2 行ずつ 0・1、C は 1 行ずつ 0・1 | ベストフィット 思考のステップ4「考えて納得！」（解答 A 2・B 4・C 上半分・D 下半分）とベストフィット 3章 類題83 解説 |
| 3 か所のスイッチ（4 路）の表 X | 000→1、001→0、010→0、011→1、100→0、101→1、110→1、111→0 | ベストフィット 思考のステップ4 問2 解答 |
| 真理値表から回路を選ぶ | X ＝ 1・1・0・1 に合う回路は ア と ウ（イ は合わない） | 学習ノート 16 実習5（解答 5: ア、ウ）。3 つの回路は自分で描き、ア＝A と NOT B を AND に入れて NOT、イ＝A AND B を B と OR、ウ＝NOT A と A AND B を OR |
| 実習4 | ⑴ A AND B を NOT → ウ（1・1・1・0）、⑵ A と NOT B を OR → エ（1・0・1・1） | 学習ノート 16 実習4（解答 4: ⑴ウ ⑵エ） |
| 排他的論理和（XOR） | 「二つの入力のうち、一方のみ 1 のときだけ出力が 1」 | ベストフィット 例題48 解説 |

**独立検算**（python・2026-09-11）: 4 つの基本表（AND・OR・XOR・NAND）を総当たりで生成し、上の表と一致。
半加算回路は S＝(A OR B) AND NOT(A AND B)、C＝A AND B を 4 通りで計算し 0110／0001。
4 路スイッチは「A と B が同じで C＝0、または A と B が違って C＝1 のとき 1」を 8 通りで計算し 1・0・0・1・0・1・1・0。
実習5 の 3 回路を 4 通りで計算し、¬(A∧¬B) と ¬A∨(A∧B) が 1・1・0・1、(A∧B)∨B は 0・1・0・1。

### 用語の線

- 「どちらか一方のときだけ 1」の回路は、学習ノートでは名前を持たない（半加算回路の S として AND・OR・NOT の組合せで出る）。
  ベストフィット 例題48 の「排他的論理和回路（XOR回路）」を使ってよい。
- 論理積回路（AND回路）・論理和回路（OR回路）・否定回路（NOT回路）の語は学習ノートの POINT ③④⑤ のとおり。
- 真理値表の行の順は 00・01・10・11（3 入力は 000〜111）。思考のステップ4 の手順で埋める。
- 「符号ビット」「2 の補数」は使わない（第2回と同じ）。「桁上げ」は学習ノート 16 の語（15 の「桁上がり」と同じ意味で、ここでは実習3 の語をそのまま使う）。

### 使わないもの（この回では触れない）

- 全加算回路（POINT ⑦）。用語の答え合わせにだけ出す。lecture 16 の参考で扱う
- 論理式の記号（∧・∨・¬）と ド・モルガンの法則。practice 03-09 類題81 に任せる
- 論理演算の優先順位
