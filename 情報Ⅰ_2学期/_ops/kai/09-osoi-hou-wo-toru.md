# 第9回 始めるのは、二つのうち遅いほう

## 難所（1つだけ）

> 待ち行列で、調理を始める時刻を「**直前の客が終わった時刻**」か
> 「**自分が来店した時刻**」の**どちらか一方だけ**で決めてしまう。
> **遅いほうを取る、という一行が抜ける。**
> 直前の終了だけにすると、**まだ来ていない客の料理を作り始めて待ち時間が負になる**。
> 来店だけにすると、**二人分を同時に作ることになって行列ができない**。
> どちらも表は最後まで埋まる。**負の数と重なりを数えるまで気づかない。**

**型**: A 境界がある
（`../nansho-guide.md` §2。境界は「直前の終了と自分の来店が等しいところ」。
そのすぐ両側で、開始時刻をどちらが決めるかが反転する）

### なぜここが難所だと言えるか（原本の重み）

- **原本の表は、境界の両側を両方含んでいる。** 2 人目は自分の来店のほうが遅く、
  3 人目から先は直前の終了のほうが遅い。**片方の決め方だけでは、どこかで必ず破綻する**
  ように数が組まれている。
- **解答 PDF がこの設問にだけ「別解」を併記している。** 待ち時間を先に出す形と、
  開始時刻を先に出す形の 2 通り。**どちらも中身は「遅いほうを取る」**で、
  出題者がこの一点を中心に見ていることが分かる。
- **空欄が 15 マスある。** 実習2 ⑴ はア〜ソまで。1 マスでも決め方を誤ると、
  そこから下が全部ずれる。**行をまたいで値が伝わる形**そのものが問われている。
- 学習ノート POINT 26 の本文は、待ち行列について
  「客が到着する時間間隔と、それぞれの客に対するサービスにかかる時間が大きな要素」
  とだけ書く。**二つの要素をどう突き合わせるかは書いていない**ので、表で気づくしかない。
- ベストフィット 4章15 と思考のステップ6 は確率的モデルを厚く扱うが、**待ち行列は扱わない**。
  この難所は学習ノート側にしかない。

### 共通テストでの現れ方（正直に書く）

**2026 年度本試験 第3問が、この待ち行列そのものを扱っている**（開隆堂の事実台帳が
全文実読した 4 試験のうちの 1 つ）。第3問はプログラムが 4 試験とも出ており、
そのうち 1 回がこの形である。効くのは次の 2 点。

- **到着・開始・終了の 3 つの時刻を、行をまたいで更新していく**形。前回・前々回で
  やった「範囲を表す変数を 2 つ更新する」形と同じ読み方が要る。
- **二つの候補から遅いほうを選ぶ**という判断。解答群がこの選び方で割れる形は、
  条件分岐を含む設問の定番になっている。

## 3点への落とし方

| | 何をするか |
|---|---|
| ① 解説ツール（A 状態判定バナー型） | 時間軸に来店の印と調理の帯を積む。**二つの候補時刻を両方出し、遅いほうに印を付ける**。決め方を「遅いほう／直前の終了だけ／来店だけ」で切り替えると、帯の並びが変わり、待ち時間が負になる客と、重なった組が数で出る。バナーが warn に変わる |
| ② プリント（A 穴埋め記述型・常体） | 例題は実習2。記入表 A で 15 マスを埋める。**テーマ二で同じ客の列を 2 通りの誤った決め方で埋めさせ**、負になった客と重なった組を数えさせる。問二は記述 ← **この回の核** |
| ③ スピードテスト | 誤答を**決め方の取り違えそのもの**にする。直前の終了をそのまま開始にする／来店をそのまま開始にする／早いほうを取る。どれもこの回の取り違えである |

## 共通の例と数値（3点で一致させる正本）

**答えの台帳は各キットの spec（my-company 側・非公開）に置く。**
ここには公開してよい設定だけを書く（`../../CLAUDE.md` §4「解答を書かない・原本を書き写さない」）。

| 項目 | 値 | 出典 |
|---|---|---|
| 主例 | 模擬店の待ち行列。客は 7 人。乱数の値は原本のまま | 学習ノート POINT 26 実習2 |
| 乱数と時間間隔 | 3 段の対応表。境目は以上と未満で分ける。値は原本のまま | 同 |
| 調理の時間 | 1 人あたり 2 分。原本のまま | 同 |
| 列の名前 | 人目／乱数／時間間隔／来店時刻／待ち時間／開始時刻／終了時刻 | 同（原本の列名をそのまま使う） |
| 決め方の名 | 遅いほうを取る／直前の終了だけ／来店だけ。**3 点ともこの 3 つの呼び方で通す** | この回で決めた |
| 数える対象 | 待ち時間が負になった客と、調理が重なった組 | この回で決めた |

**独立検算**（python・2026-09-14・scratchpad の `verify09.py`）:
乱数から時間間隔を決める境界を 11 通り、正しい決め方での 7 人ぶんの表（15 マス全部）、
誤った決め方 2 通りの表、負になった客、重なった組、待ち時間の合計と平均、
何度もまわしたときの平均の落ち着き方、サイコロの勝敗の式。**全件が原本の解答と一致。**

**検算で分かった設計上の注意（重要）**: どちらの誤りでも**表は最後まで埋まる**。
桁も飛ばないし、途中で計算が止まることもない。**「すぐおかしいと分かる」とは言えない。**
気づけるのは、負の数を見たときと、帯の重なりを数えたときだけ。
**解説ツールも速テストも、おかしさを見せる側は必ず「数える」形で作る。**

もう一点。**調理の時間を短くすると行列がほとんどできない**ので、境界のありがたみが薄れる。
解説ツールの既定は原本どおりにする。短い側は、比べるためだけに置く。

### 用語の線

- **「乱数」「確率的モデル」「待ち行列」「モンテカルロ法」「累積確率」を使う。** 学習ノート POINT 26 の語
- **時刻と時間を書き分ける。** 「来店時刻」「開始時刻」「終了時刻」は時刻、
  「時間間隔」「待ち時間」は長さ。**3 点ともこの区別を崩さない**
- **「遅いほう」で通す。** 「大きいほう」「後のほう」に言い換えない
- **待ち行列理論の記号を使わない**（範囲外）。「サービス時間」も使わず、原本どおり
  「調理から料理を受け取るまでにかかる時間」を縮めて「調理の時間」と呼ぶ
- 第5回から第8回までに引いた線をそのまま守る。**「終了値」を使わない**／**「添字」で通す**

### 使わないもの（この回では触れない）

- 円周率の近似（ベストフィット 例題67・思考のステップ6。02 の最後に名前だけ）

### 解説 25分（手持ちスライド + 解説ツール）

| 分 | 何を出すか | 話すこと |
|---|---|---|
| 0-2 | 手持ちスライド | 前回の復習を 1 枚。一段ずつ更新する話だった。今日も表を一行ずつ下へ進める |

| 15-19 | 解説ツール 01（段階2・3） | 決め方を切り替える。**直前の終了だけ**にすると待ち時間が負になる。**来店だけ**にすると帯が重なる。どちらも数で出す |
| 19-23 | 解説ツール 02（深掘り） | もう一度まわすと表が変わる。回数を増やすと平均が落ち着く。**これが確率的モデル** |
| 23-25 | まとめスライド | 開始時刻は二つのうち遅いほう。2学期はここまで。プリントの予告 |

**解説ツールで実際に動かすところ**（ここが 25 分の山場）

- 人を進める → 二つの候補時刻が並ぶ → 「この人は、どちらの時刻から始まりますか」
- 決め方を「直前の終了だけ」に切り替える → 「2 人目の待ち時間は、いくつになりましたか」
- 決め方を「来店だけ」に切り替える → 「帯が重なっているところは、何組ありますか」
- もう一度まわす → 表がまるごと変わる → 「前と同じ答えになりましたか」

### プリント演習 15分

| 分 | |
|---|---|
| 0-5 | 例題。記入表 A の 15 マスを埋める |
| 5-8 | 問二。二つの誤った決め方が、それぞれ現実の何と食い違うかを書く ← **この回の核。削らない** |
| 8-11 | 記入表 B（直前の終了だけ）。問二に書いたことを表で確かめる |
| 11-13 | 記入表 C（来店だけ）。同上 |
| 13-14 | 問一。負になった客と、重なった組を数える |
| 14-15 | 解説。**問二**の 2 点と、**問一**の数を全員に確認する |

**全部は埋まらない前提で配る。** 記入表 A だけで 15 マスある。
時間が足りないときに落としてよいのは記入表 C と問一で、**問二は落とさない**。
だから問二を記入表 B より前に置いてある（第7回・第8回と同じ組み方）。

**手が止まる生徒への一言**（答えを言わない形で）

- 「この人が来たとき、前の人の料理はもうできていますか」
- 「候補になる時刻は、いくつありますか」
- 「その二つのうち、どちらが後ですか」
- 「待ち時間が負になるのは、現実には何が起きていることになりますか」
