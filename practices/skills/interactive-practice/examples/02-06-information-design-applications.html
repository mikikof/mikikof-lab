          HTML・CSS・サイト構造

          Webページは HTML で「どんな部品がどう並ぶか(構造)」を、CSS で「どう見せるか(装飾)」を指定して組み立てる。複数のWebページをまとめた Webサイト は、ページ同士のつなぎ方で全体の構造が決まる。

          役割でまとめる主要タグ

          HTMLはタグでWebページの部品を指定する。タグは基本的に <○○>(開始)と </○○>(終了)をセットで使う。ただし <br> のように単独で使うものもある。役割で4グループにまとめると覚えやすい。

          文書の骨組み
          Structure
          html / head / body
          <html> で全体を囲み、<head> に表示しない情報、<body> に表示する内容を入れる
          例<title> はタイトルを示す(head 内)
          見出しと段落
          Text blocks
          h1〜h6 / p / br
          <hn> は見出し(n が小さいほど大きい)、<p> は段落、<br> は改行
          例<h1> はページ全体の見出しとして一つにすることが望ましい
          リンクと画像
          Link & image
          a / img
          <a href="…"> はハイパーリンク、<img src="…"> は画像を表示
          例別ページへ移動・写真を貼る
          表をつくる
          Table
          table / tr / td・th
          <table> が表全体、<tr> が一行、<td> がデータのセル、<th> が見出しのセル
          例見出しは th、中身は td で分ける
          TAG ANATOMY — タグの形
          多くは開始・終了の2つで1セット。単独で使うものもある
          html の中に head と body

          全体を <html> 〜 </html> で囲み、その中に2つの部屋を作る。<head> はタイトルや文字コードなど「ページに関する情報」、<body> はブラウザに表示される内容を書く。

          <html>
  <head>
    タイトルや文字コードの指定など、
    Webページに関する情報を記述する。
  </head>
  <body>
    文字や画像など、ブラウザの
    表示領域に表示される情報を記述する。
  </body>
</html>
          ┃<html>文書全体を囲む
          ├<head> 表示しないタイトル・文字コードなどの情報
          └<title>ページのタイトル
          └<body> 表示する画面に出る文字・画像・表など
          セレクタ { プロパティ: 値; }

          CSSはフォント・配色・レイアウトなどのスタイルを指定する技術。セレクタでどの部分に反映するかを決め、プロパティでスタイルの項目、その後に値を書く。代表的なプロパティは次の3つ。

          セレクタ { プロパティ: 値; }
例) body { background-color: #fffcdb; }
          background-color
          背景色
          要素の背景色を指定の色にする。
          記述例: background-color: #fffcdb;
          color
          文字色
          文字色を指定の色にする。色名(red, blue)でも16進数のカラーコードでも指定できる。
          記述例: color: #000080;
          border
          境界線(枠線)
          要素の境界線を引く。種類・太さ・色を指定できる。
          記述例: border: solid 1px;
          補足: 似た役割で混同しやすいのが margin(境界の外側の余白)と padding(境界の内側の余白)。どちらも「余白」だが、線の外か内かで使い分ける。
          BOX MODEL — margin と padding の違い
          border(境界線)の外側が margin、内側が padding
          網状構造 と 階層構造

          同じ管理者の複数のWebページのまとまりを Webサイト、入口にあたるページを トップページ という。各ページをハイパーリンクでどうつなぐかで、サイト全体の構造が決まる。代表が網状構造と階層構造。

          網状構造
          長所ページ間の移動がしやすい
          短所サイトの全体像がわかりにくい
          階層構造
          長所サイト内の現在地を把握しやすい
          短所目的のページまでクリック数が増える
          構造は HTML、装飾は CSS

          「何があるか(文書の構造)」は HTML、「どう見せるか(装飾の内容)」は CSS に分けて書く。たとえば「見出しにする」のは HTML、「その見出しを赤くする」のは CSS。この役割分担を押さえると、見た目の指定でどちらを使うか迷わなくなる。

          HTML + CSS — 役割を重ねて1枚に
          骨組み(HTML)に見た目(CSS)を重ねると、完成ページになる
          HTML が担当(構造)
          見出しh1〜h6 で指定
          本文・段落p で指定
          表組みtable / tr / td・th
          装飾する箇所クラス名などで指定
          CSS が担当(装飾)
          文字の色・大きさcolor / font-size
          背景色background-color
          境界線(枠線)border
          余白margin / padding
          役割分担の要点: 文字を大きくしたいときも <h1> で見出しにするのではなく、CSS の font-size を使う。<hn> は「見出し」という構造を表すタグで、装飾の道具ではない。

          ベストフィット
          HTMLのコードは全体を <html> 〜 </html> で囲み、その中でさらにヘッダ情報の部分を <head> 〜 </head>、ブラウザに表示する部分を <body> 〜 </body> で囲む。
          解説

          HTMLのタグは、基本的に <○○> という開始タグと </○○> という終了タグをセットで使う。ただし、<br> タグのように単独で使うものもある。<html>・<head>・<body> タグはHTML文書全体の構造を定義するタグで、<head> にはブラウザに表示しない情報、<body> にはブラウザに表示する情報を記述する。<h1>・<h2> タグは見出しとして使うもので、単に文字を大きくしたいときは CSS の font-size プロパティを使う。

          空欄の決め方(補足)

          ① head / ③ body: 全体は <html> で囲み、その中を「表示しない情報(②のtitleやmeta)」と「表示する内容(④以降の見出し・段落)」に分ける。前者が head、後者が body。

          ② title: head の中で、ブラウザのタブに出るページ名を示す。

          ④ h1 / ⑤ h2: 図ではいちばん大きい「情報高校の学校紹介」が大見出し(h1)、「創立」「学科」がその下の小見出し(h2)。h1 はページに一つ、h2 は複数あってよい。

          ⑥ p: 「2010年4月1日」や「普通科:6クラス…」は段落(p)。⑦ の中で改行が必要なので、<br>(⑦)で「普通科」と「情報科」を1つの段落の中で改行している。

          DOCUMENT MAP — 図とタグの対応
          完成イメージの各パーツがどのタグに当たるか
          ┃<html>文書全体
          ├<head> ①表示しない情報
          └<title> ②情報高校の学校紹介(タブ名)
          └<body> ③画面に表示する内容
          ├<h1> ④大見出し「情報高校の学校紹介」
          ├<h2> ⑤小見出し「創立」「学科」
          └<p> ⑥ + <br> ⑦段落と段落内の改行

          〈CSS〉

          CSSのセレクタには、HTMLのタグ以外にもクラス名が使用できる。クラス名はHTMLのタグに「class="クラス名"」を追加することで指定でき、そのクラス名が付いた部分に対するCSSの記述方法は「.クラス名 { プロパティ: 値; }」である。例えば、ある <p> タグに「<p class="TextBlue">」というクラス名を付けると、「.TextBlue { color: blue; }」で文字色を青にできる。次の問いに答えよ。

          ⑴CSSのセレクタとして「HTMLのタグ」「クラス名」のどちらを使用するのか、使い分けの考え方を説明せよ。
          模範解答

          HTMLのタグを使うのは、見出しや本文など 要素ごとに共通したスタイル を設定したいとき。クラス名を使うのは、注目してほしい部分など 特定の場所だけ にスタイルを設定したいときである。

          模範解答と照らして:
          ⑵問題文の例にあるCSSに「p { color: red; }」を追加しても、該当部分の文字色は青のままである。このことから、CSSのセレクタの優先順位についてどのように考えられるか答えよ。
          模範解答

          HTMLのタグとクラス名で異なるスタイルが指定されたときは、クラス名で指定されたスタイルのほうが優先順位が高い。だから p{color:red;} を足しても、クラス名の color:blue が勝って青のままになる。

          模範解答と照らして:
          ✓記述問題 — 自己採点
          解説
          • ⑴ セレクタにタグを使うときの書式は「タグ { プロパティ: 値; }」、クラス名を使うときは「.クラス名 { プロパティ: 値; }」。さらに「タグ.クラス名 { … }」のように組み合わせることもできる。共通のスタイルはタグ、特定の場所だけのスタイルはクラス名で指定する。
          • ⑵ 同じ要素にタグ指定とクラス指定が競合したときは、通常クラス名のほうが優先される。だから全体的なスタイルはタグ、特定の部分のスタイルはクラス名で指定すると、狙いどおりに上書きできる。
          SELECTOR PRIORITY — 優先順位
          同じ要素に両方が指定されたら、強いほうが勝つ
          タグのセレクタ
          書式p { … }
          範囲共通(その要素すべて)
          優先低い
          クラス名のセレクタ
          書式.TextBlue { … }
          範囲特定の場所だけ
          優先高い(こちらが勝つ)

          〈HTMLとCSS〉

          ブラウザで下の表示となるWebページについて、次の(ア)〜(カ)を、HTMLによって指定するもの・CSSによって指定するものに分類せよ。

          分類先 — 各項目をタップで選ぶ
          HTMLで指定(構造) CSSで指定(装飾)
          (ア)
          「情報の整理のための五つの基準」の下側に二重線を引く。
          (イ)
          「情報の構造化」の語句を見出しとして指定する。
          (ウ)
          「情報の整理のための五つの基準」の内容を表として表示する。
          (エ)
          表の見出しのセルの背景色を赤にする。
          (オ)
          説明の中で、赤字にする部分を指定する。
          (カ)
          「情報の構造化」の語句の左側に赤い太線を引く。
          ✓正答: HTML = (イ)(ウ)(オ) / CSS = (ア)(エ)(カ)
          解説

          HTMLは 文書の構造 を指定する言語。構造には「見出し」「本文」「リスト」「表組み」「装飾を施す箇所」などがある。(イ)は見出しの指定、(ウ)は表組みの指定、(オ)は装飾を施す箇所の指定なので、これらは HTML で指定する。

          CSSは 装飾の内容 を指定する言語。装飾には「文字の種類・色・サイズ」「要素の背景色」「境界線(枠線)の種類・色・太さ」「余白の幅」などがある。(ア)と(カ)は境界線の指定、(エ)は背景色の指定なので、これらは CSS で指定する。

          (オ)に注意(補足)

          (オ)「赤字にする部分を指定する」は HTML 側。どこを装飾するか(箇所)を決めるのは HTML(例: その部分をクラス名付きの要素で囲む)、実際に赤くする(色)のは CSS という役割分担になっている。「赤字」という言葉に引っ張られて CSS と早合点しないこと。
